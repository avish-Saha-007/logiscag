**Note on `CANONICAL_LABEL_DISTRIBUTION`'s origin.** The quantile fractions
`0.5442`/`0.9200` used in Q7b are not arbitrary cut-points chosen for this
dataset — they are exactly `CANONICAL_LABEL_DISTRIBUTION`'s own class-share
values (`{0: 0.5442, 1: 0.3758, 2: 0.0800}`, `pipeline/data.py:112-116`), so
the quantile-cutoff path doesn't only carry the train/test leak risk in
finding 10: by construction it forces *any* dataset routed through it to come
out with almost exactly a 54.42%/37.58%/8.00% class split (so the severe-delay
class is, by construction, the top ~8% of the sample, not an empirically
observed rate), regardless of that dataset's own natural delay-severity
distribution. Whether that is an intentional design choice (matching DataCo's
observed distribution so results are comparable across datasets) or an
unexamined reuse of a DataCo-specific constant on an unrelated dataset is not
established by this audit and should be documented in a follow-up.
